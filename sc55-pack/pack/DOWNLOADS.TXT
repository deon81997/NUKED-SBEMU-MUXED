=============================================================================
  NUKED SB-EMU  -  WHAT IS NOT IN THE PUBLIC RELEASE, AND WHERE TO GET IT
=============================================================================

The public release leaves out everything it may not legally share. Most of it
is optional. Put each file where it says and run SETUP / CDINST again.

-----------------------------------------------------------------------------
 REQUIRED for the SC-55 / MT-32
-----------------------------------------------------------------------------

  Roland ROMs                        -> FILES\ROMS
      SC-55 / SC-55mkII (and MT-32 / CM-32L for Munt). Roland's firmware is
      copyrighted and is not available legally for download: dump the ROMs
      from a unit you own. They are found by their contents, so the file
      names do not matter. Without ROMs you can still use a SoundFont
      (Settings > MIDI synth > SoundFont, any .SF2 file in C:\SC55\SF2).

-----------------------------------------------------------------------------
 OPTIONAL
-----------------------------------------------------------------------------

  MSCDEX.EXE  (Microsoft)            -> found automatically
      Part of Windows 98 (C:\WINDOWS\COMMAND\MSCDEX.EXE); SETUP copies it
      from there. Only needed for the REAL CD-ROM drive in DOS. Otherwise
      copy it from your own MS-DOS 6.x / Windows 9x disks to C:\SC55\CDDRV.

  VIDE-CDD.SYS  (Acer / BenQ)        -> FILES\VIDECD
      IDE CD-ROM driver, an alternative to XCDROM (which IS included, GPL,
      and works with most drives). Comes in Acer's driver package
      APICD214.EXE. Information and downloads:
        https://www.vogonswiki.com/index.php/VIDE-CDD.SYS
        https://www.dosdays.co.uk/topics/Software/optical_downloads.php

  GSCDROM.SYS  (LG / GoldStar)       -> FILES\GSCDROM
      LG CD-ROM driver, for LG drives that do not work with XCDROM. Also on
        https://www.dosdays.co.uk/topics/Software/optical_downloads.php

  QEMM 8 / 9  (Quarterdeck)          -> FILES\QEMM
      Commercial, no longer sold; only for SC55QMM.BAT. Not needed: JEMMEX
      with QPIEMU (included) does the same job (SC55JEM.BAT).

  MOUSE.COM 8.20  (Microsoft)        -> FILES\MOUSE
      Only if you prefer it to CuteMouse (included); then change the GOTO
      line in C:\SC55\MOUSE\MOUSE.BAT to GOTO MS.
