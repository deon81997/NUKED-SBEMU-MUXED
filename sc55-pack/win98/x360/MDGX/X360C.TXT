Unofficial XBox 360 Controller WDM Driver for Windows 98/98 SP1/98 SE/ME

IMPORTANT:
Make sure your XBox controller is already connected to your computer BEFORE you install this Driver!

This Driver should work with all XBox controllers brands/models.

CAUTION:
In case your XBox controller does not work or was not detected properly after installing this driver, try this:
Download this ZIP file (English):
http://www.katch.ne.jp/~morii/driver/x360c/files/20100111/x360c.w98.x86.en.zip
from this web page (Japanese):
http://www.katch.ne.jp/~morii/driver/x360c/
Extract all files from ZIP above into the same directory/folder using your favorite unZIPping tool:
http://www.mdgx.com/toy.htm#ZIP
Then do this: Start button -> Settings -> Control Panel -> Device Manager -> select your XBox controller name (as detected by Windows) -> click the Update / Install driver button -> Browse to the location where you extracted the files from ZIP above -> select (double-click) the INF file [x360c.inf] -> Apply/OK.
Reboot if prompted.

Everything here applies only to English editions.
